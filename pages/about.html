About AstroVeda

Transparent by design.

This project is built to give visitors useful free tools without requiring an account or collecting birth data for the core features.

Calculation approach

Planetary astronomy is obtained in the browser using Astronomy Engine. The Vedic layer converts tropical ecliptic longitude to a Lahiri-style sidereal longitude and derives Rashi, Nakshatra and whole-sign Lagna.

Because browser-only timezone handling cannot reproduce every historical local-time rule, professional applications should use a validated IANA timezone database and Swiss Ephemeris.

Privacy

No database, login, analytics or birth-data upload is required by the core pages. The external Astronomy Engine script is loaded from jsDelivr when the Jathagam/Panchang pages are used.

Astrology disclaimer

Astrology and numerology are traditional practices and are not scientifically established methods for predicting future events or determining compatibility. Use results as cultural or entertainment guidance.

Open source deployment

The project is plain HTML, CSS and JavaScript and can be hosted for free on GitHub Pages. See the project README for deployment steps.
